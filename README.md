# Fikrah School Management SaaS (Stage 1)

Frontend UI foundation for a multi-tenant school management platform.

## Stack

- React (Vite)
- Tailwind CSS
- React Router
- Zustand
- IndexedDB (offline queue scaffold)

## Current Stage 1 Features

- Mobile-first login page with role-based redirect
- Reusable dashboard layout for core roles
- Teacher attendance UI with offline queue and manual sync action
- Teacher score screen with grading-band scaffold

## Demo Login Users

Use any password and one of these usernames:

- `superadmin`
- `proprietor`
- `headmaster`
- `teacher`
- `parent`

## Run Locally

```bash
npm install
npm run dev
```
